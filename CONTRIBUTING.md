# Contributing to Not Nine Bar

Ideas and fixes are welcome.

- **Bug or idea:** open an issue at [github.com/thiagsants-svg/not-nine-bar/issues](https://github.com/thiagsants-svg/not-nine-bar/issues). For something in MetBarista itself, use [nakashon/metbarista](https://github.com/nakashon/metbarista/issues).
- **Pull request:** fork, `npm install`, make the change, run `npm run check` (type check, lint and tests, the same the deploy runs), open the PR against `main`.

Keep the machine safe: the app only reads from the machine except for actions the user starts (heat, brew, stop, purge, tare, preheat, load a profile), the shot's like / dislike and the piston's retraction set from the recipe.
